MAF RODA Agrobotic · 2025–present

From fruit bin to shipment

Traceability lead, Americas

When a recall happens, a packhouse needs to know where each lot came from, how it was packed, and where it went. I led an overhaul that follows fruit through sorting, labeling, palletizing, and shipping.

Architecture

One ASP.NET Core server with five enforced layers, a redesigned SQL Server database, and WPF operator apps. Corrections are appended to the traceability record so earlier events stay available for review.

On the packing line

PLC counters refresh the live model every 250 ms. A digital twin and device simulators exercise the pipeline without hardware, including integrations with sorters, printers, and ERP.

Recall and compliance

The platform produces FDA sortable spreadsheets, recall dossiers, and GS1 EPCIS 2.0 exports. Dossier generation measured 101 ms at the median and 261 ms at the 95th percentile.

From rewrite to delivery

Recovering a stalled localization platform

Senior Software Engineer / Solution Architect

Two years into a stalled global rollout, the localization team needed a simpler operator workflow and clear controls for who could view or change translation work. I led a rewrite in Java and Dart and built its role-based access controls.

The replacement cut the codebase from roughly 45,000 to 24,000 lines. First-year vendor savings were projected at about $500,000.

Approximate test speedup

A faster QA framework engineers could extend

Senior Member of Technical Staff

Writing new QA scenarios for VMware servers and appliances meant working deep inside a slow Perl framework. I designed Gemini in Python so QA and field engineers could assemble scenarios and get readable results.

About 8,000 lines of Python replaced 80,000 lines of Perl. I also built the SSH connector for remote commands and the logging library for terminal and HTML output.

DirecTV · 2007–2012

<2 months

To a working OCR pipeline

Reading set-top box screens in automated tests

Contract consulting

Automated tests needed to read on-screen text from live set-top box video. I built a C++ client/server pipeline that captures frames, processes them with an adapted FFT, and returns recognized text over TCP/IP.

I made the clients scriptable and built a server to drive multiple infrared transceivers, enabling test runs across the server farm without manual screen checks.
