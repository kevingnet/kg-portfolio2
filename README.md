# Kevin Guerra Portfolio

A standalone redesign published at <https://kevingnet.github.io/kg-portfolio2/>.

The site is static HTML and CSS. Preview it by running `python3 -m http.server 8000` in this directory and visiting <http://localhost:8000/>. The custom 404 uses the GitHub Pages project path as its base URL.

- `index.html` introduces the portfolio and highlights evidence from recent work.
- `case-studies.html`, `services.html`, `samples.html`, and `about.html` are the redesigned primary pages.
- `projects/`, `resume.html`, `experience-history.html`, and the files in `assets/` preserve the project archive and supporting materials.
- `css/portfolio-v2.css` defines the shared design. `css/style.css` supports archived layouts.

GitHub Pages publishes from the root of `main` in the separate `kg-portfolio2` repository.
